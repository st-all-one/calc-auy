# i18n / NLG

A camada de **realização linguística** (ADR-011) separa a **SRL**
(`calc-auy-nlg`) da **gramática** (`calc-auy-i18n`). A gramática é código; o
léxico é dado (`NumberWords`).

Idiomas: `pt-BR`, `en-US`, `en-EU`, `es-ES`, `fr-FR`, `de-DE`, `ru-RU`,
`zh-CN`, `ja-JP`. Idiomas podem reordenar elementos e usar grupos de **4
dígitos** (`万`/`亿`, `万`/`億`).

```console
$ calc-auy "1 + 2" --params '{"mode":"verbal","locale":"ja-JP"}'
式 一 足す 二 は 三 です。丸め：nbr5891、小数第 2 位。
```
