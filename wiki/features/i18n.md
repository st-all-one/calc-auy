# Internacionalização e Acessibilidade

## Locais Suportados

9 locales com separadores decimais, de milhar e moedas padrão:

| Locale | Idioma | Moeda | Símbolo | Sep. Decimal | Sep. Milhar |
|--------|--------|-------|---------|-------------|-------------|
| `pt-BR` (default) | Português (Brasil) | BRL | R$ | `,` | `.` |
| `en-US` | Inglês (EUA) | USD | $ | `.` | `,` |
| `en-EU` | Inglês (Europa) | EUR | € | `,` | `.` |
| `es-ES` | Espanhol (Espanha) | EUR | € | `,` | `.` |
| `fr-FR` | Francês (França) | EUR | € | `,` | ` ` (espaço) |
| `de-DE` | Alemão (Alemanha) | EUR | € | `,` | `.` |
| `ru-RU` | Russo (Rússia) | RUB | ₽ | `,` | ` ` (espaço) |
| `zh-CN` | Chinês (Simplificado) | CNY | ¥ | `.` | `,` |
| `ja-JP` | Japonês (Japão) | JPY | ¥ | `.` | `,` |

**Resolução de moeda:** se apenas `locale` é informado, a moeda é inferida da tabela. Se ambos são informados, `currency` manual tem precedência.

**Fallback:** locale não suportado → tentativa de fallback para idioma base (ex: `es-MX` → `es-ES`) → `pt-BR`.

## Formatação Monetária

`toMonetary()` utiliza **formatação customizada baseada em tabela de locales**, não `Intl.NumberFormat`. A função:

1. Obtém as definições do locale (separadores, moeda)
2. Formata a parte inteira com separador de milhar
3. Insere o separador decimal e a parte fracionária
4. Aplica o formato de moeda (prefixo `R$ `, sufixo ` €`, etc.)

**Regras de formatação de moeda:**

| Moeda | Símbolo | Posição | Espaço |
|-------|---------|---------|--------|
| BRL | `R$` | prefixo | sim |
| USD | `$` | prefixo | não |
| EUR | `€` | sufixo | sim |
| RUB | `₽` | sufixo | sim |
| CNY | `¥` | prefixo | não |
| JPY | `¥` | prefixo | não |

**Exemplos:**
```
toMonetary({ locale: "pt-BR" })           → "R$ 1.250.000,00"
toMonetary({ locale: "en-US" })           → "$1,250,000.00"
toMonetary({ locale: "fr-FR" })           → "1 250 000,00 €"
toMonetary({ locale: "en-EU", currency: "USD" }) → "$ 1.250.000,00"
```

## Acessibilidade Verbal

`toVerbalA11y()` percorre a AST recursivamente e traduz cada nó para narrativa natural, respeitando o locale ativo.

**Operadores por locale:**

| Operador | pt-BR | en-US | ja-JP |
|----------|-------|-------|-------|
| `+` | "mais" | "plus" | "たす" |
| `-` | "menos" | "minus" | "ひく" |
| `*` | "multiplicado por" | "multiplied by" | "かける" |
| `/` | "dividido por" | "divided by" | "わる" |
| `^` | "elevado a" | "to the power of" | "の" |

**Separador decimal falado:**
- `pt-BR`, `es-ES`, `fr-FR`, `de-DE` → "vírgula" / "virgule" / "Komma"
- `en-US`, `en-EU` → "point"
- `ru-RU` → "запятая"
- `zh-CN`, `ja-JP` → "点"

**Exemplo:**
```
toVerbalA11y({ locale: "en-US" })
// "12.5 multiplied by 0.15 is equal to 1 point 88 (Rounding: HALF-UP for 2 decimal places)."

toVerbalA11y({ locale: "pt-BR" })
// "12,5 multiplicado por 0,15 é igual a 1 vírgula 88 (Arredondamento: HALF-UP para 2 casas decimais)."
```

## Customização de Locale

É possível injetar um locale customizado diretamente em `toVerbalA11y()`:

```typescript
const MyLocale = {
  locale: "en-PIRATE",
  currency: "GLD",
  decimalSeparator: ".",
  voicedSeparator: " points of gold ",
  thousandSeparator: ",",
  operators: {
    add: " plus more booty ",
    sub: " less some plunder ",
    mul: " times the cannons ",
    div: " split among the crew ",
    pow: " to the power of the kraken ",
    group_start: " (avast! ",
    group_end: " ) ",
  },
  phrases: {
    isEqual: " totals to ",
    rounding: " Ship's rule ",
    for: " for ",
    decimalPlaces: " doubloons ",
  },
};

result.toVerbalA11y({}, MyLocale);
```

O objeto deve implementar a interface `CalcAUYLocaleA11y` completa, incluindo todos os operadores, frases e tokens Mermaid.
