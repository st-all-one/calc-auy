## Evidências

### T11.1 — Schema versionado
- `schema/calc_auy.proto` (projeção binária), `schema/calc_auy.schema.json`
  (JSON Schema draft 2020-12) e `schema/calc_auy.cddl` (forma *wire* canônica).
- `xtask schema` gera o JSON Schema/CDDL a partir da fonte única
  (`calc_auy_processors::schema`) e é **idempotente**; o teste
  `schema_files_match_source` detecta divergência.
- Os tipos Protobuf são gerados no build por `prost-build` com `protoc`
  vendored (`protoc-bin-vendored`).
- Evidência: `plan/evidence/E11/T11.1.txt`.

### T11.2 — Protobuf
- Mensagens `Payload`/`Node`/`Literal`/`Operation`/`Group`/`Control`/`Rational`/
  `MetaValue`/`MetaEntry`; enums `OperationType`/`RoundingStrategy`.
- Roundtrip + golden (`tests/golden/protobuf.hex`).
- Evidência: `plan/evidence/E11/T11.2.txt`.

### T11.3 — CBOR
- `ciborium` sobre a forma *wire*; determinístico (ordem de struct +
  `BTreeMap`). Golden `tests/golden/cbor.hex`.
- Evidência: `plan/evidence/E11/T11.3.txt`.

### T11.4 — MessagePack
- `rmp-serde` (`to_vec_named`) sobre a forma *wire*; determinístico. Golden
  `tests/golden/msgpack.hex`.
- Evidência: `plan/evidence/E11/T11.4.txt`.

### T11.5 — Conformidade cruzada e limites
- `cross_format_conformance`: JSON ↔ CBOR ↔ MessagePack ↔ Protobuf produzem o
  mesmo `SignaturePayload`.
- `limits_are_enforced_on_decode`: limites aplicados na reconstrução via
  `AstBuilder`.
- `unsigned_normalizes_to_signed_across_codecs`: `Uint` pequeno vira `Int` em
  todos os codecs (consistência com o JSON canônico); `Uint` grande é
  preservado.
- Evidência: `plan/evidence/E11/T11.5.txt`.

## Notas

- Rede para o crates.io disponível: `prost`, `rmp-serde`, `ciborium` e
  `protoc-bin-vendored` foram baixados (os codecs são reais, não *stubs*).
- O `protoc` não estava no `PATH`; usa-se o binário vendored via
  `Config::protoc_executable`.
- **Desvio consciente**: a geração de CDDL/JSON Schema parte de uma fonte única
  em Rust (`schema.rs`) em vez de um parser de CDDL; o `.proto` é a projeção
  binária versionada.
- `MetaValue::Uint` pequeno normaliza para `Int` no *wire* (propriedade herdada
  do JSON canônico do E03), garantindo que os quatro codecs concordem.
