# Gate G1 — Núcleo Numérico

## Data
2024-01-01

## Critérios

- [x] `Rational` híbrido com equivalência provada (`small_and_large_agree`).
- [x] Limites de bits aplicados em `new_checked`/`pow`.
- [x] Rounding com vetores por estratégia.
- [x] Baselines de benchmark registrados.
- [x] Evidência: `plan/evidence/G1.md`.

## Evidências

### T01.1 — Backend numérico
- Trait selado `Numeric` (u64, u128, BigInt) com `checked_*` verificados.
- `f64`/`f32` não implementam o trait (erro de compilação).
- Evidência: `plan/evidence/E01/T01.1.txt` (4 testes).

### T01.2 — GCD
- Binary GCD branchless para `u64`/`u128`; Euclides para `BigInt`.
- Evidência: `plan/evidence/E01/T01.2.txt` (6 testes).

### T01.3 — `Rational` híbrido
- `Repr::{Small, Large}`, invariantes `d > 0` e `gcd = 1`.
- Constantes `ZERO`, `ONE`, `HALF`; construtores `from_i64/u64/bigint`.
- `new_checked`/`new_bigint_checked` aplicam limites de bits.
- Evidência: `plan/evidence/E01/T01.3.txt` (16 testes).

### T01.4 — Aritmética
- `Add`/`Sub`/`Mul`/`Neg` infalíveis (promoção para `Large` em overflow).
- `Ord`/`Hash` canônicos; `checked_div`/`checked_rem` retornam `Result`.
- Evidência: `plan/evidence/E01/T01.3.txt`.

### T01.5 — `pow`
- Caminho inteiro com orçamento de bits (retorna `MathOverflow` antes de alocar).
- Raiz enésima exata ou `IrrationalResult`; casos `0^0`, `0^n`, `0^-n`.
- Evidência: `plan/evidence/E01/T01.5.txt` (6 testes).

### T01.6 — Rounding
- `Nbr5891`, `HalfUp`, `HalfEven`, `Truncate`, `Ceil`, `None`.
- Testes de empate (`1/2` → 0, `3/2` → 2 no `HalfEven`).
- Evidência: `plan/evidence/E01/T01.6.txt` (6 testes).

### T01.7 — Parse numérico
- Inteiro, decimal, `%`, fração `a/b`, notação científica, separador `_`.
- Sem `parse::<f64>`.
- Evidência: `plan/evidence/E01/T01.7.txt` (7 testes).

### T01.8 — Propriedades
- `small_and_large_agree`: equivalência `Small` ≡ `Large` provada via proptest.
- Axiomas de corpo: comutatividade, associatividade, distributividade, inversos.
- Evidência: `plan/evidence/E01/T01.8.txt` (69 testes no total).

### T01.9 — Benchmarks
- Baselines `criterion` por operação:

| Benchmark | Tempo |
|-----------|-------|
| `small_add` | ~42 ns |
| `small_mul` | ~65 ns |
| `small_div` | ~46 ns |
| `large_add` | ~1.53 µs |
| `large_mul` | ~28.1 µs |

- Evidência: `plan/evidence/E01/T01.9.txt`.

## Resultado
**G1 APROVADO** — Núcleo numérico implementado, provado e medido.
